# History

`samantha-build-spec.md` is the original build specification (July 2026).
Samantha was first built from it, milestone by milestone (M0 to M6 in
[DECISIONS.md](../../DECISIONS.md)). It is out of date: later corrections
removed the launch wrapper, the trust ladder, and other parts, and the
"Instructions to the implementing agent" section was for that first build.
It is kept here as a record. For how Samantha works now, read the
[README](../../README.md) and the [guide](../GUIDE.md).
